Breeze Client · startup

Real blocks. Real wind.

Every tree, leaf and grass block is a 16×16 texture on a block grid, drawn from a tinted atlas. Leaves sway in whole pixels, never fractions, so it animates like pixel art instead of like CSS. One scene, loading rail up from the first second.
